# HTML Standard

Each HTML plan is one self-contained file that works without a build step,
network connection, or external asset. Do not use Mermaid.

- Use dark mode only: declare `color-scheme: dark` and style dark backgrounds
  with readable light text everywhere, including code, tables, and SVG,
  regardless of the operating-system theme.
- Use semantic, responsive, accessible HTML with a clear heading hierarchy. Do
  not rely on color alone for meaning.
- Add a linked table of contents when the document is long.
- Make evidence, proposals, decisions, superseded material, and open questions
  easy to tell apart.
- Use inline SVG diagrams only where they clarify a decision, each with a
  plain-English explanation.
- Use relative links within the feature folder.

Before presenting, confirm links and cited paths resolve, code blocks are
labelled current or proposed, and no placeholders or stale claims remain.
